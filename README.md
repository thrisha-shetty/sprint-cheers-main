# Elevate - Employee Recognition Platform

A modern web application for recognizing and nominating team members for various awards. Built with React, TypeScript, and Supabase.


## Features

- 🏆 **Award System**: 8 different award categories for recognizing excellence
- 👥 **Team Nominations**: Nominate colleagues with ratings and comments
- 📊 **Live Leaderboard**: Real-time score tracking and rankings
- 🔐 **Authentication**: Secure email-based authentication with magic links
- 💾 **Database Integration**: Persistent data storage with Supabase
- ⚡ **Real-time Updates**: Live score updates across all users

## Prerequisites

Before you begin, ensure you have the following installed:

- **Node.js** (v18 or higher) - [Install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)
- **npm** (comes with Node.js) or **yarn**
- **Git** for version control

## Setup Instructions

### 1. Clone the Repository

```sh
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
```

### 2. Install Dependencies

The project uses the following main dependencies:

```sh
npm install
```

#### Key Dependencies:
- `react` & `react-dom` (^18.3.1) - UI framework
- `@supabase/supabase-js` (^2.79.0) - Backend and authentication
- `react-router-dom` (^6.30.1) - Routing
- `@tanstack/react-query` (^5.83.0) - Data fetching and caching
- `lucide-react` (^0.462.0) - Icons
- `tailwindcss` & `tailwind-merge` - Styling
- `shadcn-ui` components - UI components
- `sonner` (^1.7.4) - Toast notifications
- `zod` (^3.25.76) - Form validation

### 3. Environment Variables

The project uses Lovable Cloud with Supabase. Environment variables are automatically configured when deployed through Lovable:

```env
VITE_SUPABASE_URL=<your-supabase-url>
VITE_SUPABASE_PUBLISHABLE_KEY=<your-supabase-anon-key>
VITE_SUPABASE_PROJECT_ID=<your-project-id>
```

**Note**: These are auto-generated by Lovable Cloud. For local development, the `.env` file is created automatically.

### 4. Database Setup

The application uses Supabase with the following tables:

#### **profiles** table
```sql
- id: UUID (primary key)
- user_id: UUID (references auth.users)
- name: TEXT
- job_title: TEXT
- profile_picture: TEXT
- total_score: INTEGER (default: 0)
- created_at: TIMESTAMP
- updated_at: TIMESTAMP
```

#### **nominations** table
```sql
- id: UUID (primary key)
- nominee_id: UUID (references profiles.user_id)
- nominator_id: UUID (references auth.users)
- award_type: TEXT
- comment: TEXT
- rating: INTEGER (1-5)
- created_at: TIMESTAMP
```

**Database migrations are included** in `supabase/migrations/` and are automatically applied through Lovable Cloud.

### 5. Start Development Server

```sh
npm run dev
```

The application will be available at `http://localhost:5173`

## Troubleshooting

### Common Issues

**"Cannot read properties of null"**
- Ensure you're logged in
- Check that the Supabase connection is active
- Verify RLS policies are correctly configured

**Database connection issues**
- Check that environment variables are set correctly
- Verify Lovable Cloud is enabled for your project
- Check the backend status in Project Settings

**Performance issues**
- Consider upgrading instance size in Settings → Cloud → Advanced settings
- Check for console errors
- Verify real-time subscriptions are working
